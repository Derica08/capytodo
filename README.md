# Capytodo

A cozy capybara-themed to-do list.

Capytodo (Capydoto) is a cozy, gamified to-do list web application themed around a cute capybara companion named Mochi.

Key features include:

Task Management: A relaxing space to organize your daily tasks and track progress at your own pace ("A little progress goes a long way").

Virtual Companion: A built-in pet capybara (Mochi) with stats for happiness, energy, fullness, and daily streaks that you can care for.

Shop & Customization: Earn carrot coins by completing tasks to buy treats, change your capy's coat color, or customize its cozy environment.

Gentle UI: A soothing, stress-free aesthetic complete with night mode, custom animations, and gentle reminders.
